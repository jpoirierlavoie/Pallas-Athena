{# Family TEMPLATES (mcp/disclosure.FAMILIES, key "templates") — lot 2A, T10 (create_template registers a .docx already in a dossier, update_template corrects one or installs a new version of its file from such a .docx), split from FILES at T11. A template can also come from an outside file through the upload ticket (FILES, just above), and its leak check is then made against the dossier Claude names only. A replaced file is always KEPT (NEVER « template_version »), and the active special template is designated by the lawyer alone (NEVER « active_template »). #}

Gérer vos gabarits : enregistrer comme nouveau gabarit un document Word déjà versé à un dossier, tel quel (seules ses propriétés de document peuvent être effacées), et corriger un gabarit — son nom, sa description, sa catégorie, son type, ou une nouvelle version de son fichier tirée d'un tel document ou d'un fichier téléversé, la version précédente restant conservée et rétablissable. Un fichier tiré d'un document est toujours contrôlé contre le dossier de ce document : il est refusé tant que lui — ou le nom du nouveau gabarit qu'il crée — nomme encore les parties, les numéros ou les adresses de ce dossier, sauf si vous acceptez chacun d'eux. Un fichier téléversé ne l'est que si Claude nomme le dossier dont il est tiré ; sans dossier nommé, rien n'est contrôlé, et le résultat le dit. Le nouveau nom donné à un gabarit existant n'est contrôlé contre aucun dossier, alors qu'il paraît dans le nom de chaque document tiré de ce gabarit, pour tout client. Le document d'origine n'est jamais modifié.

Claude ne désigne jamais le gabarit actif des notes d'honoraires ou des notes, et n'en retire jamais la désignation — vous seul le faites : un gabarit de type « Note d'honoraires » ou « Note (impression) » n'est jamais rendu actif, et le type du gabarit actif ne change pas ici. Il peut toutefois installer une nouvelle version du fichier de ce gabarit actif, qui s'imprime aussitôt sur chaque document de ce type (la version précédente reste conservée et rétablissable). Une correction s'engage contre la version lue du gabarit : s'il a changé entre-temps, elle est refusée et rien n'est écrit.
